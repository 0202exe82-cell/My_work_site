# Показания приборов учёта: сайт

Страница, которая проверяет показания ГВС, ХВС и отопления, собирает таблицы на следующий месяц,
сводные для бухгалтерии и сводку расхода. Все расчёты идут **в браузере** (Python через Pyodide):
таблицы никуда не отправляются.

## Что лежит в репозитории

| Файл | Назначение |
|---|---|
| `index.html` | страница |
| `pokazaniya.py` | расчётное ядро (то же, что запускается из командной строки) |
| `web_api.py` | мост между страницей и ядром |
| `tests/` | тесты (`python -m unittest discover -s tests -v`) |
| `.gitignore` | чтобы реальные таблицы не попали в репозиторий |

## Публикация на GitHub Pages

1. На github.com создайте репозиторий. Насколько мне известно, на бесплатном тарифе Pages работает
   с публичными репозиториями; уточните на странице тарифов GitHub.
2. Загрузите файлы: **Add file → Upload files**. Обязательны `index.html`, `pokazaniya.py`, `web_api.py`
   (остальные по желанию), затем **Commit changes**.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`,
   папка `/ (root)`, **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
5. Откройте его, дождитесь, пока исчезнет полоса загрузки, и нажмите внизу **Самопроверка модуля**.
   Должно появиться «Модуль работает.»
6. Прогоните копии реальных таблиц и сравните с результатом командной версии.

**Не загружайте в репозиторий реальные таблицы:** репозиторий публичный. Страница обрабатывает файлы
только у вас в браузере, но всё, что вы загрузите в репозиторий, увидят все.

## Обновление

Замените `pokazaniya.py` и/или `web_api.py` и поменяйте `VERSION` в начале скрипта в `index.html`
(например, `"1.1"`): иначе браузеры могут показывать старую версию из кэша.

## Локальный запуск

```
python -m http.server 8000
```

и откройте http://localhost:8000. Двойной щелчок по `index.html` не сработает: браузер не даёт
странице читать соседние файлы.

## Ограничения

- При первой загрузке нужен интернет: расчётный модуль (около 10 МБ) и пакеты берутся с jsDelivr
  и PyPI, потом браузер хранит их в кэше. Версия Pyodide закреплена: 0.26.4.
- Файлы `.xls` читаются через библиотеку `xlrd`, которая подгружается при старте. Если она не
  загрузилась, страница попросит сохранить файлы как `.xlsx`.
- Сайт открыт всем, у кого есть адрес. Данных на нём нет, но сам инструмент доступен любому.

## Что проверено

- Тесты ядра и моста: 38 штук, один пропускается без библиотеки `xlrd`.
- Страница проверена в браузере Chromium (телефонная и широкая раскладка, светлая и тёмная темы,
  клавиатура, все три режима, скачивание архива, ошибки) на реальных таблицах.
- В этой проверке сам Pyodide заменён заглушкой, которая вызывает настоящий Python-код: в среде
  разработки не было доступа к интернету. Поэтому после публикации обязательно выполните пункт 5.
